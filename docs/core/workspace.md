# 多面板工作区

知我的窗口是一个**可分屏的多面板工作区**：把窗口向右拆成并排的几个面板，每个面板都是一套完整、独立的工作区——有自己的标签页、文件树和右栏。你可以一边看笔记、一边在旁边的面板里跟 AI 深聊，互不打扰。

## 心智模型：一个面板 = 一套完整工作区

0.9 之前，「笔记」和「智能（Agent Fleet）」是整窗切换的两种模式。0.9 起它们是**标签页**：

- 每个面板顶部有自己的**标签栏**，标签可以是一篇笔记、一个 Wiki 页，或**智能（Agent Fleet）**本身。
- 每个面板有自己的**文件树左栏**和 **AI 右栏**（交流 / 评论 / 相关 / 脉络）。
- 两个笔记面板可以各看各的文件、各开各的右栏，状态互不串。

最左侧那条**图标导航栏**（写笔记 / 🔥 智能 / 图谱 / 时间线 / 设置…）是整窗共享、固定不动的，它不属于任何单个面板。

## 向右分屏

每个面板标签栏的最右侧有一个**向右分屏**按钮，点它就在右边新开一个并排面板。

![窗口向右分屏：左面板一篇笔记（竞品调研），右面板打开「智能」消息标签，两边并排](/screenshots/workspace-split-notes-agent.jpg)

- 新分出来的面板**默认是笔记模式**——它是一块干净的工作区，你再决定往里放什么。
- 分屏之间用可拖动的**分隔条**调整宽度，比例会被记住，下次启动还在。
- 可以继续再分，形成多列并排。

::: tip 典型用法
左面板开着一篇正在写的笔记，右面板点图标栏的 🔥 打开**智能**标签，把任务派给本地 Claude Code / opencode，一边写一边看它逐字跑——不用来回切窗口。
:::

## 关闭分栏

分屏后，面板标签栏会多出一个**关闭分栏**按钮，关掉这个面板、把空间还给相邻面板。

- 当一个面板关掉它的**最后一个标签**时，这个分栏会自动收起。
- 只剩一个面板时，工作区回到单面板，和分屏前完全一致。

## 智能（Agent Fleet）也是一个标签

点最左侧图标栏的 🔥，就在当前面板打开 / 激活**智能**标签——它和笔记标签平级，可以和笔记并排分屏。智能标签内部仍是它自己的四区（消息 / 通讯录 / 看板 / 指挥室…），详见 [Agent Fleet 总览](/integrate/agent-fleet)。

面板内的侧栏折叠也统一了：

- **笔记面板**的左侧文件树、右栏都能折叠收起（0 宽度），顶栏的折叠按钮方向会指示展开 / 收起。
- **智能面板**的消息 / 协作 / 通讯录列表栏是三段式：完整 → 拖窄成头像栏 → 再拖到很窄才完全收起，永远不会留一条空白带。

## 每个面板独立持久化

面板的这些状态各自记忆、互不影响，下次启动恢复：

- 标签页与当前激活标签
- 文件树的展开 / 折叠、筛选
- 右栏是否显示、宽度、当前面板
- 左侧栏宽度
