# 桌宠

桌宠是常驻桌面的知我小形象：显示知我正在做什么，也能不打开主窗就问一句或记一笔。

在 **设置 → 外观** 里打开桌宠开关。单击桌宠打开快问面板，双击打开主窗工作台，按住可以拖动，右键打开菜单。

## 问

选好 **知我 / OpenCode / dsh**，输入后按 `Enter` 发送，`Shift+Enter` 换行，`Esc` 关闭面板。

- OpenCode 和 dsh 用的是你在 **通讯录** 里添加的 agent，模型、目录等都按那个 agent 的配置。通讯录里还没有对应的 agent 时，面板会提示「去通讯录添加」。
- 没装的 OpenCode 或 dsh 会标「未安装」，点它会打开主窗。
- 第一次用 OpenCode 时有一次提示：未配置模型时它使用免费云端模型，对话会发送到 opencode.ai。
- 关掉面板不会丢内容：上一轮和没写完的文字都还在，每个 agent 各保留一份。
- 还在运行的一轮关掉面板也会继续，重开后能看到进度和结果。
- 需要审批时会打开主窗，在那里处理。
- 右上角 **打开完整对话** 进入主窗里的对应会话。

### 新会话

左下角显示下一次新会话会用的 agent 和目录。点 **新会话**（或这个标签）会打开和主窗「+ 新会话」一样的表单：

- **Agent**：在通讯录的 OpenCode / dsh agent 之间切换。
- **Model**、**目录**（dsh 还有 **Mode** 和 **权限**）：默认用 agent 自己的配置，需要时点「更改…」。

点 **开始会话** 后，下一条消息会按这些设置开一个新会话；之后的消息继续这个会话。对话进行中不能改设置，要换就开新会话。知我的 **新会话** 只清空面板里的上一轮。

## 记

点发送键旁的 **记**（或按 `⌘/`，Windows 上是 `Ctrl+/`）切到快记。输入后按 `Enter`，内容会带时间追加到左下角显示的位置：

- **今日日记**（默认）：`日记/YYYY-MM-DD.md`
- **某个目录**：在这个目录里按天写一个文件 `YYYY-MM-DD.md`
- **某篇笔记**：追加到笔记末尾，每行带日期

```markdown
- 14:32 买牛奶
- 2026-11-01 14:32 读完第三章
```

点左下角的位置名可以切换：选今日日记、最近用过的位置，或「选择目录…」「选择笔记…」。只能选知识库里的目录和 Markdown 笔记，共享的目录会标「共享」。选择会被记住。

- 快记直写本地，不经过任何模型。
- 面板不关，输入框清空，可以连续记。
- 文件正在主窗里编辑也没关系，你没保存的内容和这条快记都会留下。
- 写入失败时内容留在输入框，可以重试；笔记被删除或目录不再属于知识库时会提示「目标已失效」，重新选一个即可。

右上角 **打开日记 / 打开笔记** 进入当前位置的文件。

## 右键菜单

右键桌宠（macOS 上也可以 `Ctrl` + 点击）：

- **快问**、**快记**、**新会话…**：打开面板到对应状态。
- **打开主窗**、**打开今日日记**。
- **对话 agent**、**快记目标**、**大小**：直接切换，面板开着会立即跟着变。
- **设置…**、**隐藏桌宠**（之后在 设置 → 外观 里重新打开）。

右键不会打开或关闭面板，也不会清掉桌宠保持的完成 / 出错表情。

## 桌宠的状态

桌宠会显示知我和你从桌宠发给 OpenCode / dsh 的任务状态：思考、执行、待审批。一轮结束后，完成或出错的表情会一直保持，直到你点击桌宠，离开电脑回来也能看到结果。取消的一轮不会保留。
