# 桌宠

桌宠是常驻桌面的知我小形象：显示知我正在做什么，也能不打开主窗就问一句或记一笔。

在 **设置 → 外观** 里打开桌宠开关。单击桌宠打开快问面板，双击打开主窗工作台，按住可以拖动。

## 问

选好 **知我 / OpenCode / dsh**，输入后按 `Enter` 发送，`Shift+Enter` 换行，`Esc` 关闭面板。

- 没装的 OpenCode 或 dsh 会标「未安装」，点它会打开主窗。
- 第一次用 OpenCode 时有一次提示：零配置下它使用免费云端模型，对话会发送到 opencode.ai。
- 关掉面板不会丢内容：上一轮和没写完的文字都还在，每个 agent 各保留一份，点 **新会话** 才清除。
- 还在运行的一轮关掉面板也会继续，重开后能看到进度和结果。
- 需要审批时会打开主窗，在那里处理。
- 右上角 **打开完整对话** 进入主窗里的对应会话。

## 记

点发送键旁的 **记**（或按 `⌘/`，Windows 上是 `Ctrl+/`）切到快记。输入后按 `Enter`，内容会带时间追加到今日日记：

```markdown
- 14:32 买牛奶
```

- 快记直写本地，不经过任何模型。
- 面板不关，输入框清空，可以连续记。
- 日记正在主窗里编辑也没关系，你没保存的内容和这条快记都会留下。
- 写入失败时内容留在输入框，可以重试。

右上角 **打开日记** 进入今日日记。

## 桌宠的状态

桌宠会显示知我和你从桌宠发给 OpenCode / dsh 的任务状态：思考、执行、待审批。一轮结束后，完成或出错的表情会一直保持，直到你点击桌宠，离开电脑回来也能看到结果。取消的一轮不会保留。
