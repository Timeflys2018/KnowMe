# 定时任务

> 0.16.0 起，定时不再是独立 tab —— **并入了[任务](/fleet/board) tab**：侧栏「定时任务」区按注意力分组（全部定时 / 今日关注 / 未来执行 / 已暂停），点行**就地**展开详情，不再整页跳转。调度能力同步扩展为**六种维度 + 两种执行内容**。

![统一定时视图：周期规则与一次性任务混排，agent 与脚本并存](/screenshots/task-schedule-unified.jpg)

## 两种「定时」

| 类型 | 来源 | 形态 |
|---|---|---|
| **周期规则（autopilot）** | 定时视图「+ 新建规则」 | ⟳ 重复执行：每天 / 每周 / 每月 / 间隔 / cron，触发后自动排下一次 |
| **一次性任务** | 任务里选「定时」派发 | ⏱ 指定时刻派发一次，触发后即完结 |

两者在统一定时列表混排、按下次执行时间排序，各自带类型 chip 与执行内容徽章（🤖 agent / ⌨ 脚本）。

## 六种调度维度

新建 / 编辑规则时选择：

| 维度 | 参数 | 示例 |
|---|---|---|
| **一次性** | 绝对时刻 | 9/5 14:00 |
| **每天** | HH:MM | 08:00 |
| **每周** | 星期几（多选）+ HH:MM | 每周一 09:30 |
| **每月** | 几号 + HH:MM | 每月 1 号 10:00 |
| **间隔** | 每 N 分钟 / 小时 | 每 2 小时 |
| **cron** | 5 段表达式 | `*/30 9-18 * * 1-5`（工作日工作时间每半小时） |

非法 / 永不匹配的 cron 会被拒绝（不会静默产生空规则）。

## 两种执行内容

- **agent**：绑定一个 agent 模板 + 提示词，到点自动派发——与手动派活同一套执行链。
- **script**（0.16 新增）：跑一段**本地 shell 脚本**（`script_path` 引用文件或 `script_inline` 内联 + 超时），产出落成一条任务记录（标题 / 状态 / 终端输出）。同步、备份、构建巡检这类不需要 LLM 的活交给脚本——**不烧任何模型额度**。

## 派发目标：Agent / 模型 / 目录 / 会话（0.22 新增）

agent 规则在编辑器里用一组「选择行」指定派发目标，点任意一行在浮层里展开选项，不会挤动下面的表单：

| 行 | 作用 |
|---|---|
| **Agent** | 规则交给哪个 agent 执行 |
| **模型** | 留「默认」则用 agent 自己的配置，也可为这条规则单独指定 |
| **目录** | 留「默认」则用 agent 的工作目录；点行后可直接输入路径，或点「选择目录」用系统对话框挑选 |
| **会话** | 到点后在哪个会话里执行，见下表 |

**会话的三种模式**：

| 模式 | 行为 |
|---|---|
| **每次新建** | 每次触发都开一个新会话（默认） |
| **沿用上次** | 接续这条规则上一次派出的会话，适合「每天在同一段对话里继续跟进」；首次触发、或上次的会话已不可用时，**自动改为新建**，不会失败 |
| **选择并绑定会话** | 始终接续你指定的那个会话，列表只显示**该 agent 在该目录下**的会话，可按标题搜索；若这个会话被删除或失效，这次触发会被标记为无效（不会悄悄改成新建），编辑器里也会提示「会话已失效，请重新选择」 |

选择「沿用上次」时，模型与目录两行会标注「仅新建会话时生效」——接续已有会话时沿用它自己的模型与目录。绑定会话时，Agent / 模型 / 目录三行改为只读，显示的是那个会话自身的设置。

**会话正忙时自动排队**：到点时如果目标会话还在运行上一轮，这次触发不会打断它，而是排队，等会话空闲后再投递。

## 到点自动执行

- 启动时 arm 所有已启用规则 + 所有一次性定时任务；错过的时间点（如 app 关闭期间）启动补偿触发。
- 周期规则触发后自动排下一次；一次性任务触发后完结。
- 规则可暂停 / 恢复：点行首的**状态按钮**一键切换，提示里可撤销；暂停的收进侧栏「已暂停」组。恢复后从下一个时间点开始，不会补跑暂停期间错过的那次。
- 侧栏默认落在「全部定时」分组（今日关注 + 未来执行，不含已暂停），也可以点到单个分组。
- 每条规则可「立即执行」跑一次看效果。

## 详情面板

侧栏点任一行，右侧就地展开：执行内容预览（提示词摘录 / 脚本）、规则卡（状态 / 重复 / 下次执行 / 执行者或脚本路径）、最近运行历史（生成的任务），以及 立即执行 / 编辑 / 暂停 / 删除 操作。

## 边界

- 定时规则只作用于**单个目标**（一个 agent 或一段脚本）——没有多 agent 自动编排；小队编排是规划中的能力。
- script 规则跑在你的系统账户下，权限边界即你的系统权限；请只配自己信任的脚本。
- agent 规则烧你配置的模型额度，知我不代理任何 key。
