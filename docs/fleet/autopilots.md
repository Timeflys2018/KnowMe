# 定时任务

> 0.16.0 起，定时不再是独立 tab —— **并入了[任务](/fleet/board) tab**：侧栏「定时任务」区按注意力分组（今日关注 / 未来执行 / 已暂停），点行**就地**展开详情，不再整页跳转。调度能力同步扩展为**六种维度 + 两种执行内容**。

![统一定时视图：周期规则与一次性任务混排，agent 与脚本并存](/screenshots/task-schedule-unified.jpg)

## 两种「定时」

| 类型 | 来源 | 形态 |
|---|---|---|
| **周期规则（autopilot）** | 定时视图「+ 新建规则」 | ⟳ 重复执行：每天 / 每周 / 每月 / 间隔 / cron，触发后自动排下一次 |
| **一次性任务** | 任务里选「定时」派发 | ⏱ 指定时刻派发一次，触发后即完结 |

两者在统一定时列表混排、按下次执行时间排序，各自带类型 chip 与执行内容徽章（🤖 agent / ⌨ 脚本）。

## 六种调度维度

新建 / 编辑规则时选择：

| 维度 | 参数 | 示例 |
|---|---|---|
| **一次性** | 绝对时刻 | 9/5 14:00 |
| **每天** | HH:MM | 08:00 |
| **每周** | 星期几（多选）+ HH:MM | 每周一 09:30 |
| **每月** | 几号 + HH:MM | 每月 1 号 10:00 |
| **间隔** | 每 N 分钟 / 小时 | 每 2 小时 |
| **cron** | 5 段表达式 | `*/30 9-18 * * 1-5`（工作日工作时间每半小时） |

非法 / 永不匹配的 cron 会被拒绝（不会静默产生空规则）。

## 两种执行内容

- **agent**：绑定一个 agent 模板 + 提示词，到点自动派发——与手动派活同一套执行链。
- **script**（0.16 新增）：跑一段**本地 shell 脚本**（`script_path` 引用文件或 `script_inline` 内联 + 超时），产出落成一条任务记录（标题 / 状态 / 终端输出）。同步、备份、构建巡检这类不需要 LLM 的活交给脚本——**不烧任何模型额度**。

## 到点自动执行

- 启动时 arm 所有已启用规则 + 所有一次性定时任务；错过的时间点（如 app 关闭期间）启动补偿触发。
- 周期规则触发后自动排下一次；一次性任务触发后完结。
- 规则可暂停 / 恢复；暂停的收进侧栏「已暂停」组。
- 每条规则可「立即执行」跑一次看效果。

## 详情面板

侧栏点任一行，右侧就地展开：执行内容预览（提示词摘录 / 脚本）、规则卡（状态 / 重复 / 下次执行 / 执行者或脚本路径）、最近运行历史（生成的任务），以及 立即执行 / 编辑 / 暂停 / 删除 操作。

## 边界

- 定时规则只作用于**单个目标**（一个 agent 或一段脚本）——没有多 agent 自动编排；小队编排是规划中的能力。
- script 规则跑在你的系统账户下，权限边界即你的系统权限；请只配自己信任的脚本。
- agent 规则烧你配置的模型额度，知我不代理任何 key。
