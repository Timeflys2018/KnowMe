# 专注模式：跟着 AI 翻它的工作文件

派活给 agent 时，你常常想边看它跑、边翻它正在改的工作文件。**专注模式**把消息面的左栏从「会话列表」切成 agent 工作目录（cwd）的**文件树**——同一个面板里，一边是流式转录，一边直接翻/改它 cwd 下的文件，不用另开窗口、不用切 app。

![专注模式 toggle：消息面头部的立方体图标，会话有 cwd 时出现](/screenshots/focus-mode-toggle.jpg)

## 开启专注：一个立方体图标

当你选中的会话**有工作目录（cwd）**时，消息面头部会出现一个**立方体（专注）图标**。点它：

- 左栏从「全局会话列表」切成该会话 **cwd 的文件树**；
- 图标高亮表示专注态已开启；
- 再点一次关闭，左栏切回会话列表。

::: tip 专注态是「面板」级、粘性的
专注开关记在**当前面板**上（不是全局）。在智能 ↔ 知识模式之间来回切，专注态**保留**；关掉某个 cwd 的专注不影响其它面板。会话没有 cwd 时，图标不显示。
:::

## 左栏 = 那个 cwd 的完整文件树

![专注开启：左栏变成 cwd 文件树（README.md / notes.md / plan.md / main.py）](/screenshots/focus-mode-cwd-tree.jpg)

这棵树**复用了知识模式左栏那套文件管理**——不是另写的简版：

- 展开/折叠子目录、按可见性设置过滤（跟随「文档树」设置）；
- 右键菜单：新建 / 改名 / 移动 / 删除；
- 拖拽移动；
- 点文件 = 在当前标签打开；`⌘`+点 = 新标签打开。

换句话说，你在专注模式里对 agent 的工作文件做的操作，和平时管理笔记文件是同一套手感。

## 点开文件：仍待在「智能」里

点开 cwd 树里的文件，面板**不会翻回知识模式**——它保持在智能壳里：左栏仍是这棵 cwd 树、顶部标签切到该文件、左侧活动栏仍高亮「智能」。这样你就是「跟着这次 agent 运行，同时看/改它的工作文件」，而不是被踢回笔记库。

![点开 plan.md：仍在智能壳，编辑器右上角是 返回消息 / 解除专注 两个图标](/screenshots/focus-mode-file-view.jpg)

编辑器**右上角**（平时放「导出」的位置）给两个图标：

- **💬 返回消息** —— 回到这个会话的消息转录（继续看它跑 / 追问）。
- **⧉ 解除专注** —— 把这个文件转成普通知识标签页（脱离 agent 上下文，右上角换回「导出」）。图标高亮表示当前处于专注文件视图。

::: tip 任何文件类型都有返回路径
这两个图标对**任意文件**都显示——markdown、代码、图片都一样——所以打开一个 `.py` 或图片工作文件时，你永远有一条回消息 / 解除专注的路，不会走进死胡同。
:::

## 前进 / 后退：`⌘[` `⌘]`

在专注文件视图里，`⌘[` / `⌘]` 走**当前面板自己的浏览历史**：连着翻了几个 cwd 文件，`⌘[` 逐个回退、`⌘]` 前进，就像浏览器的前进后退。若历史已到头（这个面板只翻过这一个文件），`⌘[` 会回到该会话的消息视图；再 `⌘]` 回到刚才那个文件。

::: warning 编辑器聚焦时的小提示
光标停在编辑器正文里时，`⌘[` / `⌘]` 会被编辑器当成「减少/增加缩进」。想用它们做面板前进后退，先点一下标签栏（把焦点移出正文）再按。
:::

## 关掉 App 再打开，左栏还是这棵树

专注打开的文件标签会**持久化**：退出 App 再进来，恢复的还是这个智能壳 + 这棵 cwd 文件树（不会变回知识库的 WIKI/RAW 树）。恢复时不会反过来把消息面的专注开关静默打开——那个开关只反映你自己的显式选择。
