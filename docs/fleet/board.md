# 任务

> 「任务」tab 是 Agent Fleet 的工作流层：**捕获 → 收集箱 → AI 整理 → 派发 → 定时 → 回顾**。0.16.0 起由旧「任务看板」升级而来——侧栏导航 7 → 6，定时并入本 tab，看板成为四种视图之一。

![收集箱：捕获条触发字符候选 + 详情面板](/screenshots/task-inbox-capture.jpg)

## 快速捕获

**全局快捷捕获窗**：任何 app 里按 `⌘⇧Space`（默认，可在 设置 → 快捷键 改成任意组合，真实注册系统快捷键）唤起屏幕中央的浮层输入框。Spotlight 式语义——唤起不把知我拉到前台，`Esc` 收起后焦点留在原来的 app。

**捕获条**（收集箱顶部与快捷窗同款）支持**触发字符候选**：

| 字符 | 属性 | 行为 |
|---|---|---|
| `#` | 标签 | 弹出已有标签候选，↑↓ 选中回车 |
| `@` | 执行者 | 我做 / Agent 做 / 人验收 + agent 候选 |
| `!` | 优先级 | 高 / 中 / 低 |
| `~` | 日期 | 弹出月历选择 |
| `^` | 清单 | 弹出清单列表选择 |

不选候选直接打字，被动解析照旧。回车后任务进收集箱。

## 收集箱与详情面板

收集箱存放 draft（仅记录）任务。**单击任意行**，右侧就地展开详情面板：标题 / 日期 / 标签 / 优先级 / 执行者 / 清单归属 / 描述，全部内联编辑；底部可删除或「立即派发」。

![收集箱详情面板：全字段内联编辑](/screenshots/task-inbox-detail.jpg)

## 清单

侧栏「清单」是一层手动分组（名称 + 图标 + 颜色）：hover「+」新建，右键重命名 / 换图标 / 删除。**删除清单只解绑任务（归属置空），不删任务**。侧栏同时有智能清单（今天 / 未来 7 天 / 已完成）与标签云，点击即过滤。

## 四种视图

顶部视图切换，同一批任务四种看法：

- **列表**：信息密度最高的日常主视图（截图见上）；右上「分组」下拉可按 **排期 / 状态 / 责任人 / 优先级** 组织列表（与排序并列，每个导航项各自记忆所选分组维）。
- **看板**：三列流转（待派发 / 进行中 / 待审核），任务卡可拖动。
- **日历**：按到期日铺月网格，我做 / Agent 做 / 人验收三色点；点某天右侧看当日安排，「今天」一键定位、标题钻取年份导航。![日历视图](/screenshots/task-calendar.jpg)
- **回顾**：本周完成 / 进行中 / 完成率 / 总任务 / 失败数 / 本周费用 KPI，配每日完成柱状图与执行者分布。![回顾视图](/screenshots/task-review.jpg)

## AI 整理

收集箱上方两个入口：

- **逐条整理**：每条草稿单独精炼（标题 / 执行者 / 日期标注），行为同旧版。
- **聚合整理**（0.16 新增）：模型看到**全部所选草稿**做 N→M 归并——每组给合并标题、含成员细节的描述、建议执行者与理由。**采纳归并组**会新建合并任务，并把成员草稿**归档**（保留溯源、可展开、可撤销，不删除）。

![聚合整理：可关联参考文档，范围跟随当前筛选](/screenshots/task-organize-cluster.jpg)

工程细节：整理范围 = 当前视图筛选后的子集（不是永远全量）；可关联一篇 vault 内 markdown 参考文档作背景；结果**流式增量**到达（「已整理 M/N 条」），后台运行不阻塞操作。逐条 / 聚合两个 persona 各自可配模型。整理烧你自己配的模型额度。

## 看板流转与任务抽屉

以下能力自旧版看板保留：

- **四列流转**：待派发（draft + scheduled）→ 进行中 → 待审核 → 已完成（终态）。
- **任务抽屉**：点任务卡打开——转录、用量面板（token / $ 花费）、续聊、打开沉淀产出物。![任务抽屉：转录 + 用量面板 + 续聊](/screenshots/fleet-board-drawer.jpg)
- **看板 ↔ 消息双向跳转**：抽屉「查看会话」↔ 消息 tab「任务」徽标。
- **降为普通会话**：任务卡右键——只摘 task 标记，完整保留会话与历史（「删除任务」才级联删会话，二次确认有区分）。

## 定时

定时不再是独立 tab：侧栏「定时任务」区按注意力分组（今日关注 / 未来执行 / 已暂停），点行**就地**展开右侧详情面板。周期规则（每天 / 每周 / 每月 / 间隔 / cron）与一次性任务在统一列表混排、按下次执行排序；执行内容可以是 **agent 提示词或本地 shell 脚本**（脚本不烧模型额度）。详见[定时任务](/fleet/autopilots)。

![统一定时视图：规则与一次性混排，agent 与脚本并存](/screenshots/task-schedule-unified.jpg)
