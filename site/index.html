一 · 一个产品，两种身份

知识引擎 × agent 指挥位，
共用同一份记忆

知我不假装 agent —— 它把你的笔记编译成可追溯的 Wiki，把这份记忆通过 MCP 开放给每一个 AI； 切到智能模式，它反过来成为指挥位，调度你本机的 OpenCode / Codex 真实 CLI 进程干活。 知识喂饱 agent，agent 反哺知识 —— 这是同一个闭环的两半。

  1. 01 · 记

    随手记录

    笔记、聊天、剪藏照单全收，不必先整理格式。

  2. 02 · 编

    AI 编译 Wiki

    抽取实体与概念，编织成可追溯的词条，写入先过 Review queue。

  3. 03 · 连

    Agent 经 MCP 读写

    Claude Code / Cursor / OpenCode 读同一份记忆，写建议同样进审核。

  4. 04 · 派

    Fleet 派活执行

    智能模式下作为指挥位，调度本机真实 CLI 干活：派活、盯盘、续聊。

  5. 05 · 归

    产出编回知识库

    agent 的成果一键入库，成为下一次提问与派活的上下文。

八 · 常见问题

还有疑问？

下载后提示"已损坏"或"无法验证开发者"怎么办？

当前为公开测试版，暂未进行 Apple 代码签名 / 公证。因此 macOS 会拦截首次打开，提示 "KnowMe 已损坏，无法打开" 或 "无法验证开发者"。

这是 macOS 对未签名 App 的标准拦截，并非 App 真的损坏，也不是病毒。按下面方法解除即可正常使用。

macOS（Apple 芯片与 Intel 通用）
  1. 双击 dmg，把 KnowMe 拖入"应用程序"文件夹。
  2. 打开"终端"（聚焦搜索 终端 或 Terminal），粘贴下面这行后回车：xattr -cr /Applications/KnowMe.app
  3. 然后到"应用程序"里双击 KnowMe 即可正常打开。

如果弹窗只给了"取消 / 移到废纸篓"，请点"取消"（不要点"移到废纸篓"，那会删掉 App），再执行上面第 2 步。xattr -cr 清除系统给下载文件打的"隔离"标记，不修改 App 本身，安全无副作用。

Windows
  1. 双击 KnowMe-Setup-0.13.2.exe 安装。
  2. 若出现蓝色 "Windows 已保护你的电脑"（SmartScreen） 提示，点击 "更多信息" → "仍要运行"。
知我和 Obsidian / Notion / Logseq 的区别？

Obsidian / Logseq 把"本地 markdown"做完了，但 AI 时代缺位。Notion 是云端协作工具，本地优先用户不喜欢。知我是双定位：知识引擎（LLM 编译 Wiki + Review queue）× agent 指挥位（MCP 原生读写双向 + Agent Fleet 调度本机真实 CLI），外加多通道发布。独占位详见上方特性区。

智能模式（Agent Fleet）为什么要登录？

智能模式是知我唯一需要登录的功能区域（邮箱 + 验证码），用于任务派发与云端编排的身份归属。本地编辑、Wiki、MCP、BYOK 全部免登录 —— 数据仍在你的本机 SQLite，登录不改变这一点。

数据真的存在我电脑上吗？联网做什么？

是的。所有笔记永远在你本地的 SQLite。联网仅在以下场景：(1) 调用 LLM 写 Wiki 编译（你的 OpenAI / Anthropic / 智谱 key）(2) 检查更新 (3) 未来可选的云同步（端到端加密，我们看不到）。
