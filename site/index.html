还有疑问？

下载后提示"已损坏"或"无法验证开发者"怎么办？

当前为公开测试版，暂未进行 Apple 代码签名 / 公证。因此 macOS 会拦截首次打开，提示 "KnowMe 已损坏，无法打开" 或 "无法验证开发者"。

这是 macOS 对未签名 App 的标准拦截，并非 App 真的损坏，也不是病毒。按下面方法解除即可正常使用。

macOS（Apple 芯片与 Intel 通用）
  1. 双击 dmg，把 KnowMe 拖入"应用程序"文件夹。
  2. 打开"终端"（聚焦搜索 终端 或 Terminal），粘贴下面这行后回车：xattr -cr /Applications/KnowMe.app
  3. 然后到"应用程序"里双击 KnowMe 即可正常打开。

如果弹窗只给了"取消 / 移到废纸篓"，请点"取消"（不要点"移到废纸篓"，那会删掉 App），再执行上面第 2 步。xattr -cr 清除系统给下载文件打的"隔离"标记，不修改 App 本身，安全无副作用。

Windows
  1. 双击 KnowMe-Setup-0.13.2.exe 安装。
  2. 若出现蓝色 "Windows 已保护你的电脑"（SmartScreen） 提示，点击 "更多信息" → "仍要运行"。
知我和 Obsidian / Notion / Logseq 的区别？

Obsidian / Logseq 把"本地 markdown"做完了，但 AI 时代缺位。Notion 是云端协作工具，本地优先用户不喜欢。知我的差异化在 MCP 原生 + LLM 编译 Wiki + 多通道发布 + agent fleet。5 大独占位详见上方特性区。

数据真的存在我电脑上吗？联网做什么？

是的。所有笔记永远在你本地的 SQLite。联网仅在以下场景：(1) 调用 LLM 写 Wiki 编译（你的 OpenAI / Anthropic / 智谱 key）(2) 检查更新 (3) 未来可选的云同步（端到端加密，我们看不到）。

用哪个模型？会不会拿我的数据去训练？

模型由你自己配置 —— 可以接入你自己的 OpenAI / Anthropic / Gemini / Ollama / LM Studio key，也可以用本地模型完全离线。知我没有任何自己的模型，也就谈不上拿你的数据训练；调用哪个模型、发送什么内容，都由你掌控。

公测期：2026-06-06 → 2027-07-06（共 13 个月），所有功能完全免费。2027-07-07 Pro 订阅正式上线，但 本地核心功能继续保留在免费档。公测期开放的高级/预览能力可能进入 Pro，Pro 主要包含自定义 Wiki Types、云同步、托管 AI、云端索引、远程 API、后台 Agent Fleet、高级导出等。
